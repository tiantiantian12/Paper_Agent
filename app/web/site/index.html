使用说明

  • 内置模型需要服务端。 客户端本身不含大模型密钥，内置模型通过你（或运营方）部署的 Paper_Agent_Server 代理调用。
  • 登录页填写「服务地址」。 例如运营方提供的 https://xxx.trycloudflare.com 或 http://IP:8000，首次注册用邮箱收验证码。
  • 自定义模型不依赖服务端。 在设置里填自己的 OpenAI 兼容 Key 与地址，可完全离线使用。
  • 系统要求。 Windows 10 / 11（64 位）；联网；建议 8GB 以上内存。
